# Calculadora EPN

## Cómo ejecutar la aplicación

Para ejecutar la aplicación utiliza **Live Server**:

1. Abre el proyecto en Visual Studio Code.
2. Instala la extensión **Live Server** (si no la tienes).
3. Abre `index.html` y haz clic derecho → **Open with Live Server**.

> No abras `index.html` directamente con doble clic (`file://`), porque los módulos ES pueden quedar bloqueados por el navegador.

## Notas

- Antes de abrir la app, compila el TypeScript con `npx tsc`.
- El código fuente está en `src/` y se compila a `dist/`.
